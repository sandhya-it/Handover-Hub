# Handover Hub 🚀
### AI-Powered Project Knowledge Transfer Platform

**Handover Hub** is an intelligent knowledge transfer platform designed to make team transitions seamless. It helps organizations capture, organize, and transfer essential project knowledge, tasks, documents, and responsibilities from one team member to another.

When a team member leaves a project or changes roles, important information can easily get lost. Handover Hub addresses this challenge by providing a centralized platform for structured handovers, ensuring that teams can continue their work without unnecessary delays or confusion.

## 🎯 Problem Statement

In many organizations, project knowledge is scattered across documents, conversations, emails, and individual team members. When responsibilities change, the incoming member may struggle to understand the project's current status, pending tasks, technical decisions, and important resources.

This leads to knowledge gaps, duplicated work, delays, and reduced productivity.

## 💡 Our Solution

Handover Hub provides a centralized digital workspace where project knowledge can be documented, organized, reviewed, and transferred efficiently.

It aims to simplify the handover process through structured information management and AI-powered assistance, helping incoming team members quickly understand their responsibilities and continue ongoing work.

## ✨ Key Features

- **Centralized Knowledge Management:** Keep essential project information organized in one place.
- **Structured Handover Creation:** Document project status, responsibilities, pending tasks, and important updates.
- **AI-Powered Assistance:** Support knowledge organization and simplify the understanding of handover information.
- **Document Management:** Maintain access to important project files and resources.
- **Task and Responsibility Tracking:** Make pending work and ownership easier to understand.
- **Seamless Knowledge Transfer:** Help incoming members understand ongoing projects faster.
- **Project Continuity:** Reduce information loss during team transitions.

## 🔄 How It Works

1. **Create a Handover:** The outgoing team member prepares a structured project handover.
2. **Add Project Knowledge:** Include tasks, progress, documents, important decisions, and pending responsibilities.
3. **Organize Information:** Keep project details accessible in a centralized workspace.
4. **Review and Transfer:** Share the handover with the incoming team member.
5. **Continue Seamlessly:** The new member uses the documented knowledge to continue the project.

## ⚙️ Getting Started

### Prerequisites
- Node.js 
- Git
- A Supabase account 

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/sandhya-it/Handover-Hub.git
```

**2. Navigate to the project**

```bash
cd Handover-Hub
```

**3. Install dependencies**

```bash
bun install
```

**4. Start the development server**

```bash
bun run dev
```

Open the local URL displayed in your terminal.
